# 1. Mục đích

Thiết kế kiến trúc của Long-Term Memory Engine cho MemoryAI.

Tài liệu này xác định:

- Các thành phần của trí nhớ dài hạn.
- Vai trò của từng thành phần.
- Quan hệ giữa các thành phần.
- Luồng đọc và ghi dữ liệu.

Không mô tả chi tiết thuật toán hay mã nguồn.

---

# 2. Mục tiêu

Long-Term Memory giúp AI:

- Hiểu lịch sử phát triển.
- Hiểu mối quan hệ giữa các dự án.
- Ghi nhớ quyết định.
- Ghi nhớ kinh nghiệm.
- Gợi nhớ công việc còn dang dở.
- Duy trì tính liên tục sau khi khởi động lại.

---

# 3. Các thành phần chính

1. Knowledge Memory
2. Timeline Memory
3. Decision Memory
4. Experience Memory
5. Reason Memory
6. Cross Project Memory
7. Project Router

---

# 4. Nguyên tắc

- Không thay đổi dữ liệu gốc.
- Mọi tri thức đều có nguồn tham chiếu.
- Quyết định phải gắn với lý do.
- Kinh nghiệm phải gắn với kết quả.
- Mọi trí nhớ đều có thể truy vết.
