# Design Principles

- Single Responsibility Principle (SRP)
- One class, one responsibility.
- One function, one purpose.
- Service Layer hides implementation details.
- Repository never contains business logic.
- Validator only validates.
- Factory only creates objects.

---

# Naming Rules

- Use meaningful names.
- Avoid Python built-in names.
- Example:
    memory_type
instead of
    type
